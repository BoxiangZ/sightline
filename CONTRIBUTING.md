# Contributing to Sightline

Thanks for taking a look. This project started from the MIT-licensed Elmo
project; see [NOTICE.md](NOTICE.md) for provenance.

## License

## Before you open a pull request

- Run `pnpm lint` and get it passing; CI fails on it.
- Run `pnpm test` for the packages you touched.
- Keep pull requests small and focused.

## Questions and reports

- Bug reports and feature requests: the repository issue tracker.
- Security issues: see [SECURITY.md](SECURITY.md) — do not open a public issue.
- Code of conduct concerns: see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
