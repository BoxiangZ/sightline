# Security Policy

We apply security fixes to the latest released version.

## Reporting a vulnerability

Do not open a public issue. Send a private report through the repository's
security advisory feature, or to the maintainer contact listed in the
repository profile. Include:

- the affected version or commit,
- a description of the issue and its impact,
- reproduction steps, if you have them.

We will acknowledge the report and keep you posted on the fix and disclosure
timeline.
